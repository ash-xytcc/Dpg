# Dual Power Gathering

Web application for the Dual Power Gathering.

The repository contains the public site, organizer workspace, API functions,
database schema and migrations, and the Docker/Traefik deployment configuration
used for dualpowergathering.org.

## Development

Install dependencies:

    npm ci

Start the local application:

    npm run dev:full

## Production

Production deployment uses Docker and Traefik. See DEPLOYMENT.md.
